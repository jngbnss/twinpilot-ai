# Safety Limitations

- 이 프로젝트의 Control Safety Layer는 **시뮬레이션 내부 규칙**이다. 실제 장비 안전을 보장하지 않는다.
- 실제 장비에 제어 명령을 보내는 기능은 없다. 실제 연결은 읽기 전용부터 시작한다.
- AI 이상 탐지 결과는 Safety Layer의 입력이 아니다. AI가 비상 정지·제한 규칙을 변경·해제할 수 없다.
- 이상 탐지는 "평소와 다른 패턴" 표시이며 고장 원인 진단이 아니다.
- 위험 판단은 시뮬레이터 ground truth 좌표 기반이다. 실제 환경의 인식 오류·지연을 반영하지 않는다.
- 물리 모델은 근사다. 전복·하중 판정은 실제 장비 한계와 다르다.
