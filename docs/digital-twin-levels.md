# Digital Twin Levels

| Level | 이름 | 내용 | 이 프로젝트 |
|-------|------|------|-------------|
| 1 | Simulation | 가상 장비 + 가상 센서만 존재 | MVP 목표 (완성) |
| 2 | Replay Twin | 기록된 센서 데이터를 재생해 가상 장비 상태 동기화 | 데이터 구조·재생 기능 준비 |
| 3 | Connected Twin | 실제 센서·장비 데이터를 실시간 연결 | 범위 밖 (읽기 전용부터 단계적 확장) |

## 표현 원칙

사용: "시뮬레이션 기반 디지털 트윈 프로토타입", "실제 장비 연동을 고려한 디지털 트윈 확장형 시뮬레이터".

사용 금지: "실제 굴착기의 완전한 디지털 트윈", "실제 장비와 동일한 물리 정확도",
"산업 현장에 바로 적용할 수 있는 안전 시스템", "실제 원격 중장비 제어 시스템".

## 실제 센서 확장 순서

1. 별도 센서 장치의 읽기 전용 데이터
2. 저장된 실제 센서 데이터 재생 (`quality="real"` 기록 → `replayed`)
3. 실시간 읽기 전용 모니터링
4. Shadow Mode (장비에 명령 없이 추천만 기록)
5. 충분한 검증 후 제한된 테스트 환경 검토
