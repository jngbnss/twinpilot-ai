# Simulation Assumptions

파라미터 단일 소스: `sim/twinpilot_sim/params/excavator.yaml`. 특정 제품 모델이 아니다.

## 출처

20톤급 유압 굴착기의 공개 제원(운전 중량 약 20 t, 붐 약 5.7 m, 암 약 2.9 m, 주행 속도 약 5 km/h,
엔진 출력 약 110 kW)을 **대략적인 규모 참고용**으로만 사용했다. 링크 질량·시정수·마찰·열 계수는
그럴듯한 거동을 내기 위한 가정값이며 측정값이 아니다.

## 모델 가정

- 지면은 평지, 미끄러짐 없음. 트랙은 차동 구동 1차 지연 모델.
- 작업 관절은 속도 명령 → 1차 지연 응답(유압 응답 근사) → 위치 적분 → 한계 클램프.
- effort = 링크·운반물 중력 토크(평면 정역학) + 점성 마찰 + 가속 항 근사. 유압 회로는 모델링하지 않음.
- roll/pitch는 상부 무게중심 이동을 지지 다각형 대비 비율로 근사한 값.
- 운반물 집기는 규칙 기반 attach/detach (D-002). 토사 변형·굴착 없음.
- 유압 온도·엔진 부하·진동·에너지는 유압 일률에서 유도한 **가상 장비 상태 값**이다 (`SIMULATED SENSOR`).
- 센서 노이즈는 가우시안, seed 고정 RNG.
